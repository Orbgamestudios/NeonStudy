# NeonStudy

**Open the live study app:** [NeonStudy on GitHub Pages](https://orbgamestudios.github.io/NeonStudy/)

A static Biochem 510 study app. Open `index.html` locally or publish the repository with GitHub Pages. Exam selection supports studying multiple exams together; the current question bank contains Exam 1 material, with Exam 2 and Exam 3 slots ready for separate content. Study progress is saved in the browser.
## Biochem 610 Exam 1

Includes 50 hint-supported short-answer calculation problems and 50 multiple-choice questions based on Lectures 1–10 and Problem Set 1. Completed calculation progress is saved locally and resumes where you left off; after all 50 are complete, you can reset the set. Select Biochem 610 Exam 1 in Study controls; choose Calculations for numeric problems or Review session for the MCQ bank.
## Molecule practice

The Review session MCQ menu includes four PubChem molecule quizzes: two 20-question amino-acid structure quizzes and one 20-question short-answer amino-acid code quiz plus 25 image-based questions on only the five DNA/RNA bases: adenine, guanine, cytosine, thymine, and uracil. The amino-acid code bank asks for both codes together (for example, `Ala A`). Structure images load from PubChem PUG REST. The live session statistics panel can be hidden and reopened; a correct streak of 3–5 triggers a one-second border lightning flash.
