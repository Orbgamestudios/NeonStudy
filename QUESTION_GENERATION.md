# NeonStudy Question-Writing Guide

Use this guide whenever adding or revising question banks in NeonStudy, especially Biochem 510 and Biochem 610 Exam 2.

## Write useful questions

- Keep each question focused on one learning objective from the exam study guide or lecture.
- Use varied formats and cognitive tasks: identify, classify, compare, predict, interpret a result, apply a mechanism, or calculate. Avoid repeating one fact with only names swapped.
- Keep wording direct. Include enough context to make the intended answer unambiguous without giving it away.
- For short-answer concept checks, author the prompt, reference answer, and scoring points in the app. Gemini 3.8 grades the learner's response; it must not invent or alter the question.

## Build fair multiple-choice options

- Provide one clearly best answer and exactly three plausible distractors.
- Keep all four options similar in length, grammar, specificity, and level of detail. The correct answer must not routinely be the longest, most qualified, or only complete sentence.
- Aim for options within roughly 20% of one another in word count unless the scientific meaning requires a difference. Revise the wording instead of padding an option with irrelevant text.
- Do not populate a question's distractors by borrowing correct answers from other questions. A borrowed answer may also be defensible for the current stem, and these swaps can reintroduce a visible length cue. Keep each stem's distractors authored for that stem.
- Make distractors relevant to the same topic. Base them on common misconceptions, nearby mechanisms, swapped steps, incorrect locations, or plausible but incorrect interpretations.
- Avoid absurd, unrelated, joke, or obviously impossible choices. Avoid giving away the answer through grammar, repeated keywords, absolutes, or option formatting.
- Check that no distractor could also be defended as correct under the question's wording. Keep choices parallel and mutually distinguishable.
- Shuffle answer position so the correct option does not repeatedly appear in one slot.

## Explain responses

- After a correct response, briefly explain the central reason the answer is correct.
- After a wrong response, mention the exact option the learner chose, connect it to the tested fact or relationship, and then state the correct answer. Do not show only a generic explanation of the key. For newly authored banks, add a concise rationale for each distractor so the explanation can address the selected misconception directly.
- Each distractor should have a concise, accurate rationale tied to the misconception it represents. If individual rationale data is not available, write feedback that contrasts the learner's chosen option with the key fact without inventing a reason.
- Explanations should teach the distinction, not simply repeat the answer.

## Cite sources and cover the guide

- Display the relevant course, topic, lecture/deck, and slide number or range with each question.
- Treat PDF page numbers as slide numbers only when one PDF page corresponds to one lecture slide; otherwise label the locator as a page.
- Cite the closest source that supports the tested fact. For questions synthesized from more than one slide, list the small relevant range rather than the full deck.
- Never invent a slide number. If the source file or locator is unavailable, state that clearly and identify the lecture/topic so it can be filled in later.
- Track coverage against every study-guide topic. Add questions for missing objectives and avoid overloading a small set of favorite facts.

## Course-specific conventions

- Follow the instructor's lecture terminology when it differs from a broader textbook convention, and identify that convention in the explanation when useful.
- For amino-acid dietary classification, use the Protein 1 lecture's convention: nine essential amino acids, cysteine and tyrosine as conditionally dispensable, and the remaining amino acids generally dispensable. Explain methionine-to-cysteine and phenylalanine-to-tyrosine precursor relationships accurately.
- Keep numerical values, units, assumptions, and calculation steps consistent with the uploaded slides and problem sets.

## Final editorial pass

Before adding a question, check that:

1. The stem tests a defined study-guide objective.
2. The key is correct and defensible from the cited source.
3. Distractors are plausible, topic-related, and balanced in length and detail.
4. Feedback addresses the selected wrong option specifically.
5. The source topic and slide/page locator are visible and accurate.
